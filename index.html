Cloud Sort: An Overhead Caller-Buffer Merge Paradigm with Zero Dynamic Allocations, 25% Bus Write Reduction, and Strict In-Situ Stability

Ashikur Rahman Green University of Bangladesh Conceived 2023 | Published Oct 2026

Textbook formulations of merge sort allocate an auxiliary array of size $N$ and execute a four-phase merge routine. Cloud Sort lifts strictly the active left slice ($A[l..m]$) to an overhead cloud buffer bounded to $\lceil N/2 \rceil$. Exploiting the novel Zero-Move Right Tail Property and enforcing an inductive read-before-write non-collision invariant ($wp_t \le rp_t$), Cloud Sort eliminates 25% of physical SRAM data writes, omits the right-side drain loop and back-copy passes, and operates with zero dynamic heap allocations (malloc/free).

An Optimal In-Situ Dual-Pointer Algorithm for Infix-to-Prefix Transformation with O(1) Auxiliary String Space

Ashikur Rahman Green University of Bangladesh Conceived Fall 2022 | Published Oct 2026

The canonical textbook pipeline for infix-to-prefix conversion mandates reversing the string, converting to postfix via a supplementary buffer, and reversing again — requiring 3 full passes and $O(N)$ string buffer duplication. This work presents an optimal dual-pointer backward scanner that parses right-to-left in a single pass, placing operands and operators directly into their terminal prefix slots in-situ with $O(1)$ auxiliary string space, saving over 60% SRAM on embedded parser architectures.
