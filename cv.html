Published Research Preprints
CERN / Zenodo Indexed
Cloud Sort: An Overhead Caller-Buffer Merge Paradigm DOI: 10.5281/zenodo.23665548
Invented & Authored by Ashikur Rahman • Published Oct 2026

Introduced an asymmetric in-situ merge sort requiring only $\lceil N/2 \rceil$ floating auxiliary memory with zero dynamic heap allocations. Formulated the Zero-Move Right Tail Property, eliminating an entire drain while-loop and reducing SRAM memory bus write transitions by 25.0%. Verified across 10,000 differential random arrays against V8 TimSort with 100.0000% precision.

In-Situ Dual-Pointer Algorithm for Infix-to-Prefix Transformation DOI: 10.5281/zenodo.23657544
Invented & Authored by Ashikur Rahman • Published Oct 2026

Formulated an optimal single-pass right-to-left transformation technique operating directly on the input buffer in $O(1)$ auxiliary string space. Eliminates the traditional textbook 3-pass requirement (reverse → postfix → reverse), cutting bus operations by >60%.
