## 🚀 Key Highlights & Architectural Features

- **Interactive 3D Universe (Three.js):**
  - Real-time 3D algorithm polyhedron with wireframe geometry and orbiting particle constellation.
  - Interactive mouse tilt and scroll-driven camera parallax traversing 3D space with linear damping (`lerp`).
  - Ultra-smooth 60 FPS WebGL rendering without external heavyweight dependencies.

- **Scientific Research Publications (CERN/Zenodo DOIs):**
  - **Cloud Sort:** An Overhead Caller-Buffer Merge Paradigm with Zero Dynamic Allocations, 25% Bus Write Reduction, and Strict In-Situ Stability ([DOI: 10.5281/zenodo.23665548](https://doi.org/10.5281/zenodo.23665548)).
  - **In-Place Infix to Prefix:** In-Situ Dual-Pointer Transformation with $O(1)$ Auxiliary String Space ([DOI: 10.5281/zenodo.23657544](https://doi.org/10.5281/zenodo.23657544)).

- **Curated Production Systems:**
  - **Demo PMS / AdisFee:** High-concurrency serverless school management and billing engine with real-time multi-tab synchronization running on Google Apps Script ([Live Demo](https://demopms.blogspot.com)).
  - **Json-Boundary:** NPM package for rapid boundary scanning and dynamic Prisma `where` clause extraction ([NPM](https://www.npmjs.com/package/json-boundary) / [GitHub](https://github.com/favouritesir/Json-Boundary)).
  - **My-mini-DNS:** ESP8266/ESP32 custom local DNS server router with simultaneous internet passthrough ([GitHub](https://github.com/favouritesir/My-mini-DNS)).
  - **mTask:** Interactive terminal task manager written in pure Bash with ANSI graphics ([GitHub](https://github.com/favouritesir/mTask)).
  - **Electron.js Task Manager:** University desktop task management application.
  - **Don Entry:** Automated cloud ledger and donation system on Google Apps Script ([YouTube Playlist](https://www.youtube.com/playlist?list=PLBUpi-NMujyW_qNiCAyxOMEKQS9MPiRU2)).
